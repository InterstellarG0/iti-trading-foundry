    Practice exercise and scanner rules

    How the team makes a decision

    Use fictional replay and paper money for the classroom exercises.

    • K–5: Assign each student one coin. Have them report whether their coin is recovering. Count the reports together and practice saying “wait” when the class rule has not been met.
    • Grades 6–8: Assign asset observers, a risk checker, and a coordinator. Write a rule for when the coordinator can add a clip and when the risk checker can stop it. Run the same replay twice and compare decisions.
    • Grades 9–12: Run two-clip and four-clip versions on the same replay. Compare worst drawdown, then use the alert log to explain one decision you would change before testing a different replay.

    Start the fictional replay. Ask what changes when selling dries up, when the basket joins the bounce, and when price turns down again. Run the same replay with different clip counts and compare the result and worst dip. Use reset to restart the same scenario.

    4h EMA and 1h direction give trend context. The 15m scanner uses RSI, Stoch RSI, stochastic and volume. Entry stages use closed 5m bars. The coordinator reads each asset’s reclaim status, Bitcoin spot flow, and basket risk. In paper bot mode it can enter one clip per fresh five-minute bar and close on a confirmed top, invalidation, or session cutoff. The alert log records the reason for each fill. Alerts appear in this tab from 5 a.m. to 10 p.m. Eastern by default. The replay uses a fictional time. Keep the tab open for live monitoring.
