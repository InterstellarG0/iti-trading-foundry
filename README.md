# ITI Trading Foundry

A browser-based paper-trading lab from Interstellar Technologies Initiative. Practice how you decide when to enter, wait, or exit a simulated crypto basket.

## Quick start

1. Open [ITI_Trading_Foundry.html](ITI_Trading_Foundry.html) on GitHub and click **Download raw file**.
2. Open the downloaded HTML in a modern browser. No installation or Kraken account is required.
3. Start the **fictional replay** and step through one candle at a time. Choose the **Kraken spot** mode to practice with live public market data. That mode requires an internet connection.

## What you can practice

- Edit the basket and its weights, set an exposure cap, and split entries into two, three, or four clips.
- Watch the entry and exit scanners, basket breadth, and Bitcoin spot trade flow.
- Use the manual controls or enable **Run paper bot** to see how the rules respond automatically.
- Start with $1,000 in simulated equity. The challenge targets +12%, prompts a review at −1%, pauses adds at −2%, and ends the run at −3%.
- Compare runs using the alert log and export completed runs as JSON. The app saves basket settings and completed runs in browser storage.

Try the same fictional replay with two clips and then four. Compare the worst drawdown and use the alert log to explain one decision you would change.

All orders and fills are simulated. Kraken supplies public spot market data without API keys.
